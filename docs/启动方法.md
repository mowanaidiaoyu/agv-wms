方法一：用项目自带脚本（推荐，最简单）
终端 1 —— 启动后端


cd C:\Users\24540\Desktop\WMS\web
.\scripts\run-backend.ps1
终端 2 —— 启动前端


cd C:\Users\24540\Desktop\WMS\web
.\scripts\run-frontend.ps1
如果 PowerShell 报「禁止运行脚本」的错，改成：
powershell -ExecutionPolicy Bypass -File .\scripts\run-backend.ps1

方法二：直接敲命令（不依赖脚本）
终端 1 —— 后端（先启动这个）


cd C:\Users\24540\Desktop\WMS\web\backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
终端 2 —— 前端


cd C:\Users\24540\Desktop\WMS\web\frontend
npm run dev
启动成功的标志
项目	地址	看到什么
后端	http://127.0.0.1:8000/	返回 {"message":"AGV simulation platform backend is running"}
后端健康检查	http://127.0.0.1:8000/api/v1/health	返回 health JSON
前端	http://127.0.0.1:5173	打开控制台首页
前端打开后，访问 http://127.0.0.1:5173/topology 就是新做的 3D 拓扑编辑器。

顺序与注意事项
先开后端、再开前端 —— 前端没有代理，是直接请求 127.0.0.1:8000 的（写死在 frontend/src/lib/api.ts 第 13 行），后端没开页面会加载不出数据。
停止：在两个终端里分别按 Ctrl + C。
端口被占用（8000 或 5173 报错）：说明有残留进程没关，先关掉旧终端，或重启一下终端再试。
换新电脑 / 删了 node_modules 或 .venv 才需要先执行一次 .\scripts\bootstrap.ps1（装依赖），日常启动不用。

开终端 A → cd C:\Users\24540\Desktop\WMS\web → .\scripts\run-backend.ps1
开终端 B → cd C:\Users\24540\Desktop\WMS\web → .\scripts\run-frontend.ps1
