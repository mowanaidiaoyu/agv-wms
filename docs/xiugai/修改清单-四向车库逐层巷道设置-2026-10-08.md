# 修改清单 —— 四向车库「逐层巷道」设置（按货架层独立编辑巷道，撤销绿色升降通道）

- **日期**：2026-10-08
- **主题**：`/topology` 3D 拓扑编辑器。四向车在四向车库内运行时，巷道**本身即可在层与层之间升降**，不需要额外的绿色升降通道。此前「层间通道（绿）」方案被撤销；本次真正补齐的是：**每个 2×2 库位按「货架层（4 层）」独立设置巷道**。数据层新增 `Zone.slotAisles` 位掩码，前后端同步落库。

---

## 背景 / 用户诉求

> 四向车在四向车库里面运行可以巷道在层与层之间升降，不需要绿色的升降通道。目前四向车库在每一层里面也需要设置巷道，但是不好去设置。

即：
1. 撤销「层间通道（绿）」第三种库位状态（升降由巷道自身承担，无需单独垂直通道）。
2. 四向车库每个 2×2 库位由 4 层货架组成，此前「巷道/货架」是一刀切作用于整个库位；本次改为**按货架层（1..4 层）逐层设置**。

## 数据模型

- `Zone` 新增字段 `slotAisles?: Record<string, number>`：
  - key = `"行,列"`（2×2 库位锚点坐标）
  - value = 4 位掩码，bit0 = 第 1 层 … bit3 = 第 4 层；该位为 1 表示该货架层是巷道。
- **旧数据兼容回退**：若某库位无 `slotAisles` 记录，按「4 格全为 road」判定——是则视为 4 层全巷道（`0b1111`），否则 4 层全货架（`0`）。

## 改动

### 1. `web/frontend/src/types.ts` / `web/backend/app/schemas.py`

- `Zone` 两侧同步新增 `slotAisles?: Record<string, number>`（Pydantic v2 会丢弃未声明字段，故必须双侧声明）。

### 2. `web/frontend/src/lib/topology.ts`

- `cloneTopology` 深拷贝 `slotAisles`。
- 新增 `shuttleSlotAisleMask(topology, zoneId, row, col, floor)`：读 `slotAisles`，带旧数据回退。
- 重写 `setShuttleSlotAisle(topology, slots, aisle, floor, level)`：按 `level` 位翻转掩码；任一货架层为巷道 → 铺 4 格 road；所有层都不是巷道 → 清 road（保证 2D 仿真通行性一致）。
- 移除旧 `setShuttleSlotLift`。

### 3. `web/frontend/src/lib/topology3d.ts`

- 移除 `shuttleLiftColor` 与 `liftAt` 提升机绿色通道渲染，提升机节点恢复原样（跨楼层黄色）。
- shuttle 槽位循环：按 `slotAisles` 位掩码计算每层 `levelColors`，`SceneRack` 新增 `levelColors?: string[]`，货架逐层按巷道（蓝）/货架（橙）分色。
- 槽位整体 `color` 仍取「全巷道=蓝 / 否则=橙」作默认。

### 4. `web/frontend/src/components/topology/Topology3DScene.tsx`

- `RackView` 层板按 `levelColors?.[level - 1]` 逐层着色。

### 5. `web/frontend/src/store/useTopologyEditorStore.ts`

- 新增状态 `activeShuttleLevel`（1..4）与 `setActiveShuttleLevel`（夹到 1..4）。
- `applyShuttleAisle` 传 `activeShuttleLevel` 作为目标层。
- 移除 `applyShuttleLift`。

### 6. `web/frontend/src/components/topology/TopologyPropertyPanel.tsx`

- 移除 `applyShuttleLift` / `onApplyLift` 全部残留。
- `ShuttleBatchEditor`：去掉「设为层间通道」按钮，两个按钮改为「第 N 层设为巷道 / 第 N 层恢复货架」。
- `ShuttleSlotEditor`：改为显示「第 N 层 · 巷道/货架」，列出 4 层各自状态，一键切换当前层。

### 7. `web/frontend/src/pages/TopologyPage.tsx`

- `EditorContextBar` 在存在 shuttle 区域时新增「货架层」选择器（第1..4 层），复用 `topology-floor-chip` 样式，切换 `activeShuttleLevel`。

## 验证结果

- `npx tsc -b` ✅ 无输出
- `npx vitest run` ✅ 12/12 passed

## 交互 / 行为变化

- 顶部出现「货架层」切换（仅当画布内存在四向车库区域）。
- 选一个库位，右侧面板显示 4 层各自是「巷道」还是「货架」；切换「货架层」后，面板针对**当前层**提供「设为巷道 / 恢复货架」按钮。
- 框选多个库位，可批量设置**当前层**为巷道或货架。
- 3D 视图里货架层板按层分色：蓝色层=巷道（四向车在该层通行），橙色层=货架（存储）；四向车沿巷道在各层间上下移动，无需绿色通道。
