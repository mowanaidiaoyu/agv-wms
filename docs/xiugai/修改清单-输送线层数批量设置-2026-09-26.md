# 修改清单 —— 输送线层数「框选批量设置」

- **日期**：2026-09-26
- **主题**：`/topology` 3D 拓扑编辑器，把输送带「单层 ↔ 双层」从「逐块点击」改为「框选一部分，一次性批量设置」。全部集中在前端，**后端与仿真逻辑零改动**。

---

## 背景

输送带按 2×2 块建模，此前属性面板改「层数」只联动当前这一个 2×2 块（4 格），要改一段线得逐块点「修改」，体验很差。

> 需求澄清：不是「整条连通线一起改」，而是**框选一部分**再批量设置层数。

## 改动

### 1. `frontend/src/store/useTopologyEditorStore.ts`

1. 新增选择类型 `conveyor-batch`（`ids: string[]` 为格子 id + `box` 框选范围），并在 `isValidSelectionForTopology` 中按「仍是输送带格」过滤保真。

2. 新增动作 `selectConveyorBatch(ids, box)`：设置 `selection` 为该批量选择。

3. 新增动作 `updateConveyorLevels(ids, levels)`：把给定输送带格的 `levels` 统一改为指定值。

4. 选择工具「拖框」结束分支（`pointerUpAt`）：框选内**优先**识别输送带格，按 2×2 块归并（`conveyorBlockCellIds`）后作为 `conveyor-batch` 选中；无输送带格再回落到原来的库位批量（`storage-batch`）；都没有则提示「框选区域没有输送带或库位节点」。

```ts
const conveyorCells = draft.cells.filter(
  (cell) => cell.type === 'conveyor' &&
    (cell.floor ?? GROUND_FLOOR) === activeFloor && isPointInBox(box, cell.row, cell.col),
)
if (conveyorCells.length) {
  const blockIds = new Set<string>()
  for (const cell of conveyorCells) for (const id of conveyorBlockCellIds(draft, cell.id)) blockIds.add(id)
  get().selectConveyorBatch([...blockIds], box)
} else { /* 原库位批量逻辑 */ }
```

5. `updateCell` 保持「层数只联动当前 2×2 块」，未被改成整线联动。

### 2. `frontend/src/components/topology/TopologyPropertyPanel.tsx`

新增 `ConveyorBatchEditor`（样式对齐既有 `StorageBatchEditor`）：显示框选范围与格子数，提供「批量层数」下拉（单层/双层）+「应用到 N 格输送带」按钮，点击调 `updateConveyorLevels`。

主组件在选择为 `conveyor-batch` 时渲染该编辑器。

### 3. `frontend/src/components/topology/Topology3DScene.tsx`

`highlightIds` 把 `conveyor-batch` 与 `storage-batch` 一并处理：选中的输送带块（带面 box）高亮。

## 验证结果

- `npx tsc -b` ✅

## 交互/行为变化

- 用「选择」工具在输送线上拖一个框 → 框内的输送带块（按 2×2 归整）整体高亮，右侧面板出现「输送带批量」。
- 在该面板选「单层 / 双层」并点应用 → 框选这部分输送带一次性改层数，无需逐块点击。
- 单块点选时改「层数」仍只影响该 2×2 块，与之前一致。
- 框选区域若同时有库位节点则优先按输送带处理；纯库位区域仍走原「库位批量」。
