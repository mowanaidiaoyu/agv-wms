# 修改清单 —— 拓扑编辑器（多项修改汇总）

- **日期**：2026-10-10
- **主题**：`/topology` 3D 拓扑编辑器。同一天连续做了 7 项修改，本清单合并记录。前 6 项围绕四向车库（shuttle 区域）的槽位编辑；第 7 项新增通用的「批量选择」操作方式（两次点击定矩形，可批量选择 / 批量放置）。

---

## 1. 货架层切换补强（属性面板内即可选层）

- **诉求**：> 目前似乎只能将第一层设置为巷道，无法选择第二层。
- **根因**：货架层（1..4）切换器只放在顶部「楼层」旁，离右侧属性面板的编辑按钮太远，用户在面板里点「设为巷道」时不知道要先回顶部切层，实际一直作用在第 1 层。
- **改动**（`web/frontend/src/components/topology/TopologyPropertyPanel.tsx`）：
  - 新增 `ShuttleLevelChips` 小组件：4 个「第1层…第4层」chip，复用 `topology-floor-chip` 样式，点选即切 `activeShuttleLevel`。
  - `TopologyPropertyPanel` 读取 `setActiveShuttleLevel`，作为 `onLevelChange` 传入 `ShuttleSlotEditor` / `ShuttleBatchEditor`，两处都加「货架层」chip 行。
  - 顶部切换器保留，两处同步（共享同一 `activeShuttleLevel`）。

## 2. 单个槽位删除（挖空为空位，可恢复）

- **诉求**：> 目前批量生成的四向车库是一个整体，不能单个删除。
- **数据模型**：`Zone` 新增 `removedSlots?: string[]`（被删槽位的 `"行,列"` 列表），前后端双侧声明（`web/frontend/src/types.ts` / `web/backend/app/schemas.py`）。
  - 在 `removedSlots` 中 = 空位；不在 = 正常槽位（货架或逐层巷道）。
  - 删除时同步清掉该槽位的 `slotAisles` 掩码、槽位 4 格内格子、落位该 2×2 的 storage 节点；恢复时仅移除标记（回到默认货架）。
- **改动**：`topology.ts`（`cloneTopology` 深拷贝、`shuttleSlotRemoved`、`setShuttleSlotRemoved`）；`topology3d.ts`（空位渲染）；store 新增 `applyShuttleSlotRemove`；`TopologyPropertyPanel` 两个编辑器各加「删除该槽位 / 恢复该槽位」按钮。

## 3. 槽位标记随区域平移保持

- **诉求**：> 为什么删除了某个槽位之后，只要移动就会恢复？
- **根因**：`slotAisles` 与 `removedSlots` 的键是**绝对网格坐标** `"行,列"`，移动区域时 `updateZoneGeometry` 只改 `x/y`，没有同步平移这些键，移动后读不到旧标记，表现为「被删槽位恢复、巷道标记丢失」。
- **改动**（`web/frontend/src/lib/topology.ts`）：`updateZoneGeometry` 在 `x/y` 变化时按 `(dRow, dCol)` 同步平移 `slotAisles` / `removedSlots` 的键；新增私有 `translateSlotAisleKeys` / `translateRemovedSlotKeys`。纯缩放不改 `x/y`，不触发平移。
- **备注**：road 巷道格（地面层通行格）目前仍不随区域平移，若后续发现 2D 仿真通行格错位，再单独处理。

## 4. 删除槽位后移除占位层

- **诉求**：> 为什么删除对应槽位之后，还会有一层东西在那里占位？
- **根因**：第 2 项为了让空位仍可点击恢复，给被删槽位渲染了一个低矮低透明灰方块占位，视觉上就是「多了一层东西」。
- **改动**（`topology3d.ts`）：命中 `removedSlots` 的槽位直接 `continue`，不再渲染占位方块，空位完全露出底板与楼板。
- **恢复方式**：删除后立即在面板「恢复该槽位」；之后用「选择」工具框选该空位 → 批量面板「恢复选中槽位」。

## 5. 删除槽位改用「贴地线框」标记（可见、可点选、可框选）

- **诉求**：第 4 项彻底隐藏后，批量选中/恢复时看不到空位在哪，体验不好。
- **改动**（`topology3d.ts` / `Topology3DScene.tsx`）：被删槽位渲染一个**贴地浅灰线框**（`wire: true`、`#94a3b8`、无填充），既标出空位、又不像「多了一层东西」；仍带 `shuttle-slot` entity 可点选恢复。`SceneBox` 新增 `slotRow/slotCol`；`shuttle-slot` / `shuttle-batch` 高亮由「只匹配 rack」扩展到含线框标记。

## 6. 框选矩形可见性修复（真正的「批量选中看不到」）

- **诉求**：> 我说的是进行批量选中时，我看不到是否正在批量选中。最好有类似方框之类的框选。
- **根因**：框选预览矩形原渲染在楼板层 `activeFloorY + 0.06`（厚 0.05、opacity 0.22），被 5.6 高的货架柱遮挡，几乎看不见。
- **改动**（`web/frontend/src/components/topology/Topology3DScene.tsx`）：
  - 框选预览从楼板层改为**浮到场景最高点之上** `spec.maxY + 0.9`（`maxY` 为全部 zone 顶高，货架 5.6 也在其下），任何角度可见。
  - 视觉改为「**半透明填充 + 矩形描边方框**」：填充 `boxGeometry` 厚 0.06、`#22d3ee`、opacity 0.25、`depthWrite={false}`；描边用 `lineSegments`（4 边 / 8 顶点，`#67e8f9`）画出清晰矩形边框。
  - 描边顶点由 `useMemo`（`marqueeFramePoints`）按框选宽高实时计算；命中判定逻辑不变。

## 7. 新增「批量选择」操作方式（两次点击定矩形，可批量选择 / 批量放置）

- **诉求**：> 增加一种操作方式，批量选择，在该操作下可以批量放置也可以批量选择，通过先点击确认开始位置，后点击确认结束位置。
- **设计**：新增独立工具 `'batch'`（不替换现有 `选择` 工具的拖动框选）。激活后：点第 1 下确认起点（出现单格标记）→ 移动鼠标实时拉出方框预览 → 点第 2 下确认终点，按上下文条所选「动作」执行。
- **改动**：
  - `web/frontend/src/types.ts`：`EditorObjectType` 新增 `'batch'`。
  - `web/frontend/src/lib/topology.ts`：`OBJECT_LABELS.batch = '批量选择'`；新增 `BATCH_PLACE_TYPES`（批量放置可选对象：3 种铺格 + 11 种节点）与 `cellsInBox(box)`（矩形内格点枚举）。
  - `web/frontend/src/components/TopologyGlyph.tsx`：新增 `batch` 矩形方框图标（复用 select 的框线）。
  - `web/frontend/src/components/topology/ObjectPalette.tsx`：`TOOL_HINTS.batch` + 指针组新增「批量选择」按钮。
  - `web/frontend/src/store/useTopologyEditorStore.ts`：新增 `batchAction`（`select|place`）、`batchPlaceType`、`batchOrigin` 状态与 `setBatchAction`/`setBatchPlaceType`；抽取 `selectBatchAt(box)`（原 select 拖动批量选择逻辑：输送带块→库位节点→四向槽位）与 `runBatch(box)`（`select` 走 `selectBatchAt`；`place` 走 `paintStroke`/`fillNodes`）；`pointerDownAt` 两次点击、`pointerEnterAt` 实时方框预览；`cancelGesture`/`setActiveTool`/`setActiveFloor`/`beginNew`/`setLoaded` 清理 `batchOrigin`。
  - `web/frontend/src/pages/TopologyPage.tsx`（`EditorContextBar`）：`activeTool === 'batch'` 时显示「批量：选择/放置」chip + 放置对象下拉（`BATCH_PLACE_TYPES`）。
  - `web/frontend/src/components/GridBoard.tsx`：`objectLabels` 补 `batch`（满足 `Record<EditorObjectType,string>` 穷尽）。

## 交互 / 行为变化汇总

- 选中一个/框选多个库位 → 面板内「货架层」chip 直接切层，「设为巷道 / 恢复货架」作用于当前层。
- 单点/框选可「删除槽位（挖空）」与「恢复槽位」；空位显示为贴地浅灰线框，可点选恢复。
- 删除槽位或设巷道后移动区域，标记随区域平移不丢失。
- 选择工具拖拽框选时，场景上方实时显示青蓝色「方框」（描边 + 半透明填充），松手即消失。
- 新增「批量选择」工具：点起点→移鼠标拉方框→点终点；「选择」命中输送带块/库位/四向槽位并进入对应批量面板；「放置」按所选对象批量铺格或放节点；Esc 中途取消。
