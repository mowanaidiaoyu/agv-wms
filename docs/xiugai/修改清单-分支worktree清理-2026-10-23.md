## 执行内容

1. **摘除 Junction（关键安全步骤）**：`pyc-c-unified` 里的 `.venv` 与 `frontend\node_modules` 是指向 `WMS\web` 实体目录的 Junction。先用 `[System.IO.Directory]::Delete(path, false)` 仅删除链接本身，未触碰目标目录；删除后核验 `web\.venv\Scripts\python.exe` 与 `web\frontend\node_modules\vite` 完好。
   - 注意：不能用 `Remove-Item -Recurse` 直接删含 Junction 的目录（PowerShell 5.1 可能递归进目标删除实体文件）。
2. **移除 worktree**：`git worktree remove --force` + `git worktree prune`。`pyc-c-unified` 一次移除成功；`pyc` 因 node_modules 超长路径（>260 字符）移除与 `Remove-Item` 均失败，改用 robocopy 空目录镜像法（`robocopy 空目录 pyc /MIR` 后删除空目录）清空并删除文件夹。
3. **删除本地分支**：`git branch -D pyc`（409d641）、`git branch -D pyc-c-unified`（b8cb21d）。两者的提交都是 `merge-pyc` 历史的祖先（分别经 f632edb、3e25c27 合入），且远端 `origin/pyc`、`origin/integration/pyc-c-unified` 仍在 GitHub，可随时恢复，无任何代码丢失。
4. **清理演示残留**：`pyc-c-unified\backend\app_data` 下的数据库拷贝随 worktree 一并删除；web 的正式数据库（`web\backend\app_data\agv_platform.db`）未受影响。
