## 一、货架调高（每层高度按区域类型）

**背景**：此前货架层高是全局 `LEVEL_HEIGHT = 0.5`，四向车平库 4 层 × 0.5 = 2 个单位，看起来太矮。改为按区域类型区分：CTU 料箱 0.5、四向车托盘 1.4。

### 1. `frontend/src/lib/topology3d.ts`

新增按区域类型的层高常量：

```ts
/** 货架每层高度（按区域类型）：CTU 料箱 0.5，四向车托盘 1.4（平库货位更高）。 */
export const ZONE_LEVEL_HEIGHT: Record<ZoneType, number> = {
  ctu: 0.5,
  shuttle: 1.4,
  station: 0.5,
  buffer: 0.5,
  conveyor: 0.5,
  mixed: 0.5,
}
```

`SceneRack` 接口新增 `levelHeight: number`，货架分支与取景高度按区域层高：

```diff
   levels: number
   slotSize: number
+  levelHeight: number
   color: string
```

```diff
   items.push({
     kind: 'rack',
     ...
-    slotSize: zone.type === 'shuttle' ? 2 : 1,
+    slotSize: 1,
+    levelHeight: ZONE_LEVEL_HEIGHT[zone.type],
     ...
   })

-  maxY = Math.max(maxY, y + (levels > 1 ? levels * LEVEL_HEIGHT : FLOOR_HEIGHT))
+  maxY = Math.max(maxY, y + (levels > 1 ? levels * ZONE_LEVEL_HEIGHT[zone.type] : FLOOR_HEIGHT))
```

### 2. `frontend/src/components/topology/Topology3DScene.tsx`

`RackView` 立柱高度与层板 y 用 `rack.levelHeight`（原 `LEVEL_HEIGHT`），并从 import 移除 `LEVEL_HEIGHT`：

```diff
-    const rackHeight = rack.levels * LEVEL_HEIGHT
+    const rackHeight = rack.levels * rack.levelHeight
   ...
-      shelves.push(rack.y + level * LEVEL_HEIGHT - 0.05)
+      shelves.push(rack.y + level * rack.levelHeight - 0.05)
   ...
-  const rackHeight = rack.levels * LEVEL_HEIGHT
+  const rackHeight = rack.levels * rack.levelHeight
```

效果：四向车平库 4 层 × 1.4 ≈ 5.6 个单位高，与托盘货位体量匹配。

## 二、四向车库拆成「巷道 + 库位」分色显示

**背景**：四向车库此前渲染为一块连续货架，看不到内部巷道。改为：库位（2×2 托盘位）画成橙色库位柱，巷道（通行路）路面用蓝色区分——类似输送线「立柱 + 带面」的分层结构。

### `frontend/src/lib/topology3d.ts`

1. 新增巷道色常量与 `zoneById` 索引：

```ts
const aisleColor = '#3a4f6e' // 四向车库内巷道（通行路），与普通路面色区分

const zoneById = new Map<string, Zone>()
for (const zone of topology.zones) {
  zoneById.set(zone.id, zone)
}
```

2. 路面渲染：属于 shuttle 区域的 road 格用巷道蓝：

```diff
   if (cell.type === 'road') {
+    const zone = cell.zoneId ? zoneById.get(cell.zoneId) : undefined
+    const isShuttleAisle = zone?.type === 'shuttle'
     items.push({
       ...
-      color: cellColor.road,
+      color: isShuttleAisle ? aisleColor : cellColor.road,
     })
   }
```

3. 四向车库区域不再画整块货架，改画薄底板 + 线框边界：

```diff
-  if (levels > 1) {
+  if (zone.type === 'shuttle') {
+    // 薄底板 + 线框边界（库位/巷道由 storage 节点与 road 格分别上色）
+    items.push({ kind: 'box', position: [cx, y + 0.06, cz],
+      size: [zone.width * CELL, 0.12, zone.height * CELL],
+      color: baseColor, emissive: baseColor, opacity: 0.3, ... })
+    items.push({ kind: 'box', position: [cx, y + 0.08, cz],
+      size: [zone.width * CELL + 0.06, 0.16, zone.height * CELL + 0.06],
+      color: baseColor, wire: true, ... })
+  } else if (levels > 1) {
     items.push({ kind: 'rack', ... })
   }
```

4. shuttle 库位节点画成 2×2 × 4 层橙色库位柱：

```diff
   if (node.type === 'storage') {
+    if (nodeFootprint(topology, node) === 2) {
+      const binW = CELL * 2 * 0.92
+      const binH = ZONE_LEVELS.shuttle * ZONE_LEVEL_HEIGHT.shuttle   // 4 × 1.4
+      items.push({ kind: 'box',
+        position: [x + CELL / 2, y + binH / 2, z - CELL / 2],
+        size: [binW, binH, binW],
+        color: zonePadColor.shuttle, emissive: '#7c2d12', opacity: 0.85, ... })
+    } else {
       items.push({ ... 原 1×1 库位小盒 ... })
+    }
     continue
   }
```

## 三、四向车（shuttle_robot）占 2×2 格

**背景**：四向车在巷道中移动，应和四向车库位一样占 2×2。

### 1. `frontend/src/lib/topology.ts`

`nodeFootprint` 把 `shuttle_robot` 纳入（归属 shuttle 区域 → 2）：

```diff
-/** 节点占地边长：库位节点归属四向车平库时为 2（2×2），其余为 1（1×1）。 */
+/** 节点占地边长：库位节点或四向车归属四向车平库时为 2（2×2），其余为 1（1×1）。 */
 export function nodeFootprint(...) {
-  if (node.type !== 'storage') return 1
+  if (node.type !== 'storage' && node.type !== 'shuttle_robot') return 1
   return findZoneById(topology, node.zoneId ?? '')?.type === 'shuttle' ? 2 : 1
 }
```

> `shuttle_robot` 的 `NODE_ZONE_AFFINITY` 已是 `['shuttle']`，放进四向车库自动拿到 shuttle 的 zoneId，占地推导即生效。

四向车渲染为 2×2 盒子（中心在 2×2 块中心）：
