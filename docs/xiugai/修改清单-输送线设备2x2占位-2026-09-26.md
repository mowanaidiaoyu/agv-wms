# 修改清单 —— 输送线设备 2×2 占位与双层对齐

- **日期**：2026-09-26
- **主题**：`/topology` 3D 拓扑编辑器，把输送带上的设备（闸口 / 缓存位 / 升降移载机 / 转向移载机）与提升机统一为 2×2 占位，并让设备贴齐输送带带面（单层/双层自动对齐）。全部集中在前端，**后端与仿真逻辑零改动**。

---

## 一、占位 2×2（移载机 / 闸口 / 缓存位 / 提升机）

**背景**：输送带已按 2×2 块建模，但落在输送带上的设备仍是 1×1，放到输送线里对不齐。

### `frontend/src/lib/topology.ts` — `nodeFootprint`

按「处理托盘 → 2×2，处理料箱 → 1×1」重写：

```diff
-/** 节点占地边长：库位节点或四向车归属四向车平库时为 2（2×2），其余为 1（1×1）。 */
+/** 节点占地边长：处理托盘的节点 2×2，处理料箱的节点 1×1。 */
 export function nodeFootprint(...) {
+  const zoneType = findZoneById(topology, node.zoneId ?? '')?.type
+  // 输送带上的设备（闸口 / 缓存位 / 移载机）固定 2×2，与输送带块同口径
+  if (node.type === 'conveyor_gate' || node.type === 'buffer' ||
+      node.type === 'lift_transfer' || node.type === 'turn_transfer') {
+    return 2
+  }
+  // 库位 / 四向车：四向车库位(托盘) 2×2，CTU 料箱位 1×1
+  if (node.type === 'storage' || node.type === 'shuttle_robot') {
+    return zoneType === 'shuttle' ? 2 : 1
+  }
+  // 提升机：CTU 料箱 1×1，托盘(输送 / 四向 / 混合) 2×2
+  if (node.type === 'lift') {
+    return zoneType === 'ctu' ? 1 : 2
+  }
+  return 1
 }
```

> 因 `nodeFootprint` 被 `placeNode` / `moveNode` / `findNodeAt` 复用，2×2 的越界/重叠校验、点选命中自动生效，无需另改。

## 二、吸附到 2×2 输送带块锚点

**背景**：设备 2×2 后，若落在输送带块的奇数格上会跨块错位。改为落位时吸附到块锚点（偶偶坐标），与输送带块同格对齐。

### `frontend/src/lib/topology.ts` — `placeNode` / `moveNode`

两处落位入口各加一段（`placeNode` 用 `type`，`moveNode` 用 `node.type`）：

```ts
// 输送带上的设备（闸口/缓存位/移载机）吸附到 2×2 块锚点，与输送带块同格对齐
if (CONVEYOR_MOUNTED_NODE_TYPES.has(type)) {
  const hit = findCell(topology, row, col, floor)
  if (hit?.type === 'conveyor') {
    const anchor = conveyorBlockAnchor(row, col)
    row = anchor.row
    col = anchor.col
  }
}
```

同时把错误文案由「2×2 库位」泛化为「2×2 节点」（现对移载机/提升机同样适用）：

```diff
-  return { topology, message: '2×2 库位超出网格范围。' }
+  return { topology, message: '2×2 节点超出网格范围。' }
-  return { topology, message: '该区域已被其它节点占据，放不下 2×2 库位。' }
+  return { topology, message: '该区域已被其它节点占据，放不下 2×2 节点。' }
```

## 三、渲染 2×2 与双层带面对齐

### `frontend/src/lib/topology3d.ts`

1. 新增 `cellAt` 索引（`楼层:row:col` → 格），供设备读取其下输送带格的层数：

```ts
const cellAt = new Map<string, TopologyCell>()
for (const cell of topology.cells) {
  cellAt.set(`${itemFloor(cell)}:${cell.row}:${cell.col}`, cell)
}
```

2. 输送带设备渲染为 2×2，**替换该段带面、与带面同一层高**（不是叠在带面之上；单层居中 0.42，双层覆盖 0.42~0.84）：

```ts
if (node.type === 'conveyor_gate' || node.type === 'buffer' ||
    node.type === 'lift_transfer' || node.type === 'turn_transfer') {
  const under = cellAt.get(`${floor}:${node.row}:${node.col}`)
  const onConveyor = under?.type === 'conveyor'
  const levels = onConveyor ? Math.max(1, under.levels ?? 1) : 1
  const baseH = node.type === 'conveyor_gate' ? 1.2
    : node.type === 'lift_transfer' ? 0.9
    : node.type === 'buffer' ? 0.5 : 0.35
  const w = CELL * 2 * 0.96
  if (onConveyor) {
    const span = (levels - 1) * 0.42   // 双层时覆盖上下两条带
    items.push({
      kind: 'box',
      position: [x + CELL / 2, y + 0.42 + span / 2, z - CELL / 2],
      size: [w, baseH + span, w], color, floor, entity,
    })
  } else {
    items.push({   // 未落在带面上：贴地
      kind: 'box',
      position: [x + CELL / 2, y + baseH / 2, z - CELL / 2],
      size: [w, baseH, w], color, floor, entity,
    })
  }
  continue
}
```

3. 提升机由 1×1 塔（`tower`）改为 2×2 立柱（`box`），仍跨楼层：

```diff
   if (node.type === 'lift') {
-    items.push({ kind: 'tower', height: spans * FLOOR_HEIGHT, ... })
+    const w = CELL * 2 * 0.9
+    items.push({
+      kind: 'box',
+      position: [x + CELL / 2, y + (spans * FLOOR_HEIGHT) / 2, z - CELL / 2],
+      size: [w, spans * FLOOR_HEIGHT, w],
+      color, emissive: '#a16207', opacity: 0.85, ...
+    })
     continue
   }
```
