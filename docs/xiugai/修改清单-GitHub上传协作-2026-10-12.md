## 8. 输送带块支持「奇数起点」（同日追加）

- **诉求**：输送带是 2×2 块、锚点强制向下取偶，只能落在「偶偶」格。在一个 4 格条带上，2 格宽的输送带只能放「左两格 / 右两格」，放不到「中间两格」。需要让块能以任意格（含奇数）作锚点。
- **难点**：旧代码用「floor 到偶」作为由任意格推导块锚点的确定性映射（无需存储），并靠「偶偶格 = 块锚点格」决定渲染与整块联动；一旦允许奇锚点，该映射不再唯一，必须把块锚点**显式存到每个格子**。
- **设计**：给 `TopologyCell` 增加可选 `conveyorAnchor: {row,col}`，旧数据（无该字段）回退到 floor-到-偶，保持完全兼容；绘制时锚点 = 所点格子本身（不再 floor）；用「重叠保护」（目标 4 格若已属于别的输送带块则整块拒绝）让连刷/框刷自然以「每 2 格一块、起点任意」铺出连续线。
- **改动**：
  - `web/frontend/src/types.ts` + `web/backend/app/schemas.py`：`TopologyCell` 新增 `conveyorAnchor`（前端 `conveyorAnchor?: {row,col} | null`，后端 `conveyorAnchor: dict[str,int] | None = None`，后端必须声明否则保存时被 Pydantic 丢弃）。
  - `web/frontend/src/lib/topology.ts`：新增 `conveyorAnchorOf(cell)`（存的 anchor ?? floor-到-偶 回退）与 `conveyorBlockCellsAt(anchor)`；`conveyorBlockCells` 重构为 `conveyorBlockCellsAt`；`conveyorBlockCellIds` / `placeNode` / `moveNode` 的节点吸附改走 `conveyorAnchorOf`；`paintSingleCell` 增 `anchor` 参数并写入/清除 `conveyorAnchor`；`paintConveyorBlock` 锚点=所点格 + 重叠保护；`snapConveyorAnchors` 由 floor-到-偶去重改为按格子去重；`moveConveyorRun` 位移吸附由偶网格改为任意整数、新格显式写随动的 `conveyorAnchor`；`cloneTopology` 深拷贝 `conveyorAnchor`。
  - `web/frontend/src/lib/topology3d.ts`：渲染跳过条件由「偶偶格才画」改为「仅块锚点格才画」（`conveyorAnchorOf`），奇偶均可。
  - `web/frontend/src/store/useTopologyEditorStore.ts`：`moveCell`/`pointerUpAt` 的 `conveyor-run` 位移吸附改任意整数；`bindConveyorSegment` 块计数去重改 `conveyorAnchorOf`。
  - `web/frontend/src/components/topology/TopologyPropertyPanel.tsx`：`ConveyorRunEditor` 逐块去重改 `conveyorAnchorOf`。
- **验证**：`npx tsc -b` 无输出；`npx vitest run` 全通过（新增奇锚点/重叠保护/奇位移平移等单测，共 23 tests）。
- **范围边界**：只改编辑器数据模型 + 渲染 + 绘制/移动/整块联动；块尺寸保持 2×2，不引入 1×2 / 单格粒度；相邻错位块重叠时拒绝；不改后端路径规划/仿真对 conveyor 的语义。
