# 修改清单 —— 拓扑编辑器 3D 化改造

- **日期**：2026-09-08
- **主题**：`/topology` 拓扑编辑器由「2D 画布编辑 + 3D 只读预览」改造为「纯 3D 编辑器」，删除 2D 视图，3D 场景本身即可完成增删改查。
- **交互约定**：左键 = 编辑 / 点选；右键 = 旋转视角；中键拖动 / 滚轮 = 平移缩放。

## 本次改动文件（共 7 个）

### 1. `frontend/src/lib/topology3d.ts`（新增功能）
- 新增 `worldToCell(x, z, cols, rows)`：世界坐标 → 网格坐标（`worldX/worldZ` 的逆运算，含边界 clamp）。
- 新增 `floorPlaneY(floorIndex)`：楼层 → 世界基准高度。
- 新增 `SceneEntityKind` / `SceneEntity` 类型：`{ kind: 'cell'|'node'|'zone'|'resource'; id; floor }`。
- `SceneBox` / `SceneRack` / `SceneTower` / `SceneSlab` 增加可选 `entity?` 字段。
- `buildSceneSpec()` 生成时给每个物体填充身份元数据（cell/节点/区域/资源标记 → 对应 entity）。

### 2. `frontend/src/components/topology/Topology3DScene.tsx`（整体重写为可交互）
- 由「只读预览」重写为「可交互编辑器」。

export function floorPlaneY(floorIndex: number): number {
  return floorIndex * FLOOR_HEIGHT

export function worldToCell(x: number, z: number, cols: number, rows: number): { row: number; col: number } {
  const col = Math.round(x + cols / 2 - 0.5)
  const row = Math.round(rows / 2 - z - 0.5)
  return {
    col: Math.max(0, Math.min(cols - 1, col)),
    row: Math.max(0, Math.min(rows - 1, row)),

}

# 补充改动 —— 节点批量放置（拖拽矩形填充）

- **日期**：2026-09-08
- **主题**：为节点工具（库位/站台/缓存/入口/闸口/交叉点/提升机/CTU/四向车）补充「拖拽拉矩形 → 每格放一个同类型节点」的批量放置手势；单击仍是放单个（1×1 矩形），工具保持激活可连续批量铺设。解决逐格点击铺库位货架耗时、以及「先选工具再逐点放入」体验差的问题。
- **关键事实**：`zone` 的货架由 zone 矩形渲染，`zoneId` 命中的 storage 节点不单独画；因此「拉一个 CTU/四向车 zone → 拖拽填满同区域 storage 节点」即铺满整面货架，密集填充语义正确。

## 本次改动文件（共 3 个）

### 1. `frontend/src/lib/topology.ts`（新增 `fillNodes`）
新增纯函数，在归一化矩形框内逐格复用 `placeNode` 落位规则（自动铺路、自动归属 zone），跳过被拒/越界格：

```ts
export function fillNodes(
  topology: TopologyPayload,
  type: NodeType,
  box: CellBox,
  floor = GROUND_FLOOR,
): { topology: TopologyPayload; placed: number } {
  let current = topology
  let placed = 0
  for (let row = box.row0; row <= box.row1; row += 1) {
    for (let col = box.col0; col <= box.col1; col += 1) {
      const result = placeNode(current, type, row, col, floor)
      if (result && !result.message) {
        current = result.topology
        placed += 1
      }
    }
  }
  return { topology: current, placed }
}
```

# 补充改动 —— 3D 视图拖动 / 缩放体验（平移可拖动 + 指向光标缩放）

- **日期**：2026-09-09
- **主题**：修复「3D 拓扑只能随场景中心缩放、无法方便拖动平移」的问题。原 OrbitControls 把平移绑在中键（`MIDDLE: MOUSE.PAN`），滚轮缩放沿视线朝固定 `target`（场景中心）推进，大行列拓扑下难以定位到某块区域。
- **新交互约定**：左键 = 编辑 / 点选；**右键拖动 = 平移视图**；**滚轮 = 缩放（指向光标）**；**中键拖动 = 旋转视角**。

# 补充改动 —— 缩放锚点修正（真正指向鼠标位置）

- **日期**：2026-09-09
- **主题**：上一版 `ZoomToCursor` 里缩放落位有一处求值顺序 bug——`camera.position.copy(hit).add(camera.position.clone()...)` 会先 `copy(hit)` 改掉 position，导致后面 `.clone()` 取到的已是新值，缩放锚点错误（视觉上不是「指向鼠标」）。
- **修复**：先基于缩放前的位置算偏移，再落位：

```diff
-      camera.position.copy(hit).add(camera.position.clone().sub(hit).multiplyScalar(scale))
-      orbit.target.copy(hit).add(orbit.target.clone().sub(hit).multiplyScalar(scale))
+      const camOffset = camera.position.clone().sub(hit).multiplyScalar(scale)
+      const targetOffset = orbit.target.clone().sub(hit).multiplyScalar(scale)
+      camera.position.copy(hit).add(camOffset)
+      orbit.target.copy(hit).add(targetOffset)
```

- 仅 `frontend/src/components/topology/Topology3DScene.tsx` 改动；后端零改动。
- 验证：`npx tsc -b` ✅、`npm run test` ✅ 2 passed。
