# 修改清单 —— 四向车库「看不到」修复（巷道/底板/线框抬高）

- **日期**：2026-09-27
- **主题**：`/topology` 3D 拓扑编辑器，四向车库（shuttle 区域）在 3D 里看不到。根因是底板、线框、巷道（road 格）都被画在不透明楼板内部被遮挡。全部集中在前端，**后端与仿真逻辑零改动**。

---

## 背景 / 根因

四向车库在 3D 里只有 2×2 的橙色库位柱可见，底板 / 线框 / 蓝色巷道全都看不到，空的四向车库看起来就是「没有」。

数值事实（3D 中 `CELL=1`，`FLOOR_HEIGHT=4`）：

| 元素 | 渲染中心 Y | 高度 | 占据范围 | 结果 |
| --- | --- | --- | --- | --- |
| 每层楼板 slab | +0.09 | 0.18 | 0 ~ 0.18（不透明） | — |
| 四向车库底板 | +0.06 | 0.12 | 0 ~ 0.12 | 被楼板盖住 |
| 四向车库线框 | +0.08 | 0.16 | 0 ~ 0.16 | 被楼板盖住 |
| 巷道 road 格 | +0.02 | 0.04 | 0 ~ 0.04 | 被楼板盖住 |

这本质是 09-23「四向车库拆成巷道 + 库位分色」埋下的：分色依赖 road 格可见，而 road 格一直低于楼板顶（0.18）。

## 改动（全部在 `frontend/src/lib/topology3d.ts`）

把这三类元素抬到楼板顶（0.18）之上，纯渲染高度调整、逻辑零改动：

1. **road 格**（巷道/普通路面）：`position` `[x, y + 0.02, z]` → `[x, y + 0.2, z]`（厚 0.04 → 占据 y 0.18~0.22，贴楼板顶）。四向车库内巷道用 `aisleColor` 蓝、普通路面 `cellColor.road`，一并可见。

2. **四向车库底板**：`position` `[cx, y + 0.06, cz]` → `[cx, y + 0.21, cz]`，`size` 高度 `0.12` → `0.1`，`opacity` `0.3` → `0.4`。

3. **四向车库线框**：`position` `[cx, y + 0.08, cz]` → `[cx, y + 0.26, cz]`，`size` 高度 `0.16` → `0.2`。

> 相机取景高度已由 `maxY = levels * ZONE_LEVEL_HEIGHT.shuttle = 5.6` 覆盖（[topology3d.ts:438](web/frontend/src/lib/topology3d.ts#L438)），橙色库位柱本就在取景范围内，无需改相机。

## 四、四向车库位改为 4 层货架（货架回来了）

**背景**：09-23 把四向车库位从「整块货架」拆成「2×2 库位柱」，但库位柱当时画成了一整根实心橙柱（高 5.6 = 4 层 × 1.4），看不出「4 层」，用户问「四向车库的货架去哪了」。

**改动**：`frontend/src/lib/topology3d.ts` 里 `node.type === 'storage'` 且占地 2×2 的分支，由单个 `box`（实心柱）改为 `rack`（复用既有货架渲染 `RackView`）：

```ts
items.push({
  kind: 'rack',
  key: node.id,
  x: x + CELL / 2, z: z - CELL / 2, y,
  cellsW: 2, cellsD: 2,
  levels: ZONE_LEVELS.shuttle,          // 4
  slotSize: 2,                          // 仅 4 角立柱
  levelHeight: ZONE_LEVEL_HEIGHT.shuttle, // 1.4
  color: zonePadColor.shuttle,          // 橙
  zoneType: 'shuttle', label: node.label, floor, entity,
})
```

效果：每个 2×2 库位现在渲染为「4 角立柱 + 4 层层板」的 4 层货架，与 CTU 货架同一种视觉语言；巷道（蓝）与库位（橙 4 层货架）分色仍保留。

## 验证结果

- `npx tsc -b` ✅
- `npx vitest run` ✅ 12/12 passed（topology.test 10 + TopologyPage + App）

## 交互/行为变化

- 拉一个「四向车库」区域 → 立即能看到橙色底板 + 线框（不再「看不到」）。
- 在区域内铺「road」巷道 → 显示蓝色巷道；铺「库位」→ 橙色 2×2 库位柱。
- 非 shuttle 区域的普通路面（road 格）也由「不可见」变为浅色路纹，可看清通行路铺装范围。
